# libris

A collection of desktop publishing projects: books, magazines, comics, created with Scribus, using public-domain literary works as source material.

The purpose of this repository is to demonstrate practical skills in : book layout, magazine layout, comics layput, typography, page composition, image preparation, color management, and print/digital publishing workflows.

Used software: <a href="https://wiki.scribus.net/canvas/Scribus"
                target="_blank"
                >Scribus</a>
